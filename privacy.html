Moi Dashboard: Privacy Policy

Last updated: 27 October 2026. Applies to the Windows and Android apps called Moi Dashboard («Мой дашборд»).

1. Who we are

Moi Dashboard is a personal organizer developed by an individual developer. Contact: uducuucjsjsjjs@gmail.com. The app has no servers of its own: the developer does not receive, store or process any user data.

2. Data the app works with

The user enters records into the app: sleep times, study schedule, grades, attendance, study sessions, commute records and game timers. This data is stored locally on the user's device (in a local database or app storage). Other data, such as finances or health notes in the PC version, stays on the PC only and is never synced.

3. Google user data

If the user chooses to turn on sync, the app requests one Google API scope: https://www.googleapis.com/auth/drive.appdata (view and manage the app's own configuration data in Google Drive). Through it the app:

  • creates, reads, updates and deletes only its own files in the hidden application-data folder of the user's Google Drive (one file per device, containing the records of the synced blocks: sleep, study, commute and game timers);
  • reads the signed-in account's email address to show which account is connected in the settings.

The app cannot access any other files in Google Drive. The sync files are not encrypted by the app and are stored only in the user's own Google account. Access tokens are stored on the user's device only.

4. How data is used, shared and retained

  • Data is used only to show the same records on the user's own devices.
  • Data is not sold, shared or transferred to the developer or any third party, and is not used for advertising, profiling, analytics or to train AI models.
  • The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Data stays on the user's devices and in the user's Google Drive until the user deletes it.

5. User control and deletion

  • Sign-out in the app settings removes the sign-in from that device.
  • Access can be fully revoked at myaccount.google.com/permissions. The app's hidden data can be deleted in Google Drive settings (Settings → Manage apps → Moi Dashboard → Delete hidden app data) or with the "Forget device" function in the app.
  • Deleting the app removes its local data from the device.

6. Security

Communication with Google uses HTTPS. The app does not send data anywhere except Google (accounts.google.com, oauth2.googleapis.com, www.googleapis.com).

7. Changes

If this policy changes, the new version will be published on this page with an updated date.
