# Мои скриншоты 0.2.0 (бета) — программа для ПК (Windows 10/11)

Делает и сохраняет скриншоты, как ShareX: выделение области, весь экран, активное окно, горячие клавиши, значок в трее, автозапуск вместе с Windows. Внутри есть редактор снимков, преобразователь в негатив (чёрное ↔ белое), как на сайте batchtools.pro, запись экрана и видеоредактор.

## Запуск

1. Установи [Node.js](https://nodejs.org) (версия LTS), если его ещё нет.
2. Дважды щёлкни `START.bat`. При первом запуске он один раз скачает Electron и ffmpeg (нужен интернет, примерно 200 МБ), потом откроется окно.

## Сборка установщика

Дважды щёлкни `BUILD-INSTALLER.bat`. Через 5–10 минут в папке `dist` появятся два файла (нужен только один):

- `Moi-Screenshot-Setup-0.2.0.exe` — обычная установка с ярлыком на рабочем столе и в меню «Пуск»;
- `Moi-Screenshot-Portable-0.2.0.exe` — запускается без установки.

**Если сборка падает с «Cannot create symbolic link».** Windows не даёт создавать символические ссылки без прав. Запусти `BUILD-INSTALLER.bat` правой кнопкой → «Запуск от имени администратора» или включи Параметры → Для разработчиков → «Режим разработчика».

Данные в обоих вариантах лежат в одном месте, при удалении программы они не стираются.

## Как пользоваться

| Что | Как |
| --- | --- |
| Выделить область | `PrintScreen`, потом тянешь рамку мышью. `Esc` или правая кнопка — отмена |
| Весь экран | `Ctrl+PrintScreen` (монитор, на котором стоит мышь) |
| Активное окно | `Alt+PrintScreen` |
| Меню программы | правый клик по значку в трее, левый клик открывает окно |

Сочетания можно поменять в «Настройки → Съёмка». Рядом с каждым написано, удалось ли занять клавишу. Четвёртое сочетание, `Ctrl+Shift+PrintScreen`, делает шаг серии для лабораторной.

**Если PrintScreen «занят».** В Windows 11 эту клавишу по умолчанию забирает «Ножницы». Отключи: Параметры → Специальные возможности → Клавиатура → «Использовать кнопку Print Screen для запуска снимка экрана». Или выбери другое сочетание, например `Ctrl+Shift+S`.

## Что происходит после снимка

На вкладке «Снимок» отмечаешь галочками, что делать (можно всё сразу):

- копировать в буфер обмена, чтобы сразу вставить в чат или документ;
- сохранить файл в папку (по умолчанию `Изображения\Скриншоты`, имя по дате и времени);
- открыть в редакторе;
- показать уведомление.

Любой снимок попадает в «Историю». Если «Сохранять в папку» выключено, снимок хранится только внутри программы.

## Редактор

Стрелка, линия, рамка, овал, карандаш, маркер, текст, нумерация (①②③), пиксели, размытие, **негатив области**, обрезка. Цвет и толщина, отмена и возврат (`Ctrl+Z`, `Ctrl+Y`), `Ctrl+S` сохраняет в тот же файл, `Ctrl+C` копирует картинку. Кнопка «Негатив всего снимка» переворачивает цвета целиком. Зажми `Shift`, чтобы линия шла под 45° или рамка была квадратной.

## Негатив

Вкладка «Негатив»: открой файлы, перетащи их в окно, вставь из буфера или возьми из истории.

- **Полный негатив** — как на batchtools.pro: чёрное становится белым, цвета меняются на противоположные.
- **Только яркость** — светлое становится тёмным, а цвета остаются: удобно, чтобы сделать тёмную версию белого скриншота.
- Прозрачность (PNG) сохраняется.
- Можно обработать сразу много файлов: рядом с исходными (к имени добавится `_negative`, оригиналы не трогаются) или в выбранную папку.

## Запись экрана

Вкладка «Запись»: выбери «Весь экран», «Окно» или «Область» (рамка тянется так же, как для скриншота) и нажми «Начать запись» или `Ctrl+Shift+R`.

- **Звук:** системный и микрофон, у каждого своя громкость 0–200%. **Веб-камера** показывается в углу кадра кругом или прямоугольником (угол и размер в настройках).
- **Панель:** маленькое окошко с таймером, паузой и «Стоп». Оно поверх всех окон и в запись не попадает. Пауза — `Ctrl+Shift+P`, запись области — `Ctrl+Shift+A`. Всё то же есть в меню трея. Обратного отсчёта нет.
- **Формат:** MP4 (H.264 + AAC, открывается везде) или WebM. 15, 30 или 60 кадров в секунду, качество низкое, среднее или высокое.
- **Папка записей:** по умолчанию `Изображения\Скриншоты\Записи`, меняется в «Настройки → Запись».
- **Лимиты** (чтобы запись не съела диск): максимум минут, максимум мегабайт и минимум свободного места. При достижении запись сама останавливается и сохраняется.
- Во время записи видео пишется кусками во временный файл в папке данных. Если программа или Windows закрылись, при следующем запуске недописанная запись восстановится.
- Что делает программа: при записи занимает процессор и диск (кодирование делает встроенный ffmpeg, он запускается только на время записи или экспорта и закрывается после), сеть не использует.

## Видеоредактор

Вкладка «Видео» (или кнопка «В видеоредактор» у записи). Исходные файлы не меняются: результат сохраняется отдельным файлом рядом с исходником, к имени добавляется `_монтаж`.

| Что | Как |
| --- | --- |
| Добавить видео | «Добавить видео» (mp4, webm, mkv, mov, avi, gif) или «Из записей». Несколько клипов склеиваются по порядку |
| Воспроизвести | `Пробел`, клик по линейке времени, стрелки `←` `→` (с `Shift` — по секунде) |
| Разрезать | `S` на месте маркера |
| Обрезать | потяни края клипа на дорожке |
| Вырезать кусок посередине | `I` — начало, `O` — конец, `X` — вырезать (то, что после, сдвинется) |
| Скорость, громкость, «без звука» | панель «Клип» справа; порядок клипов — кнопки ← и → |
| Надпись, стрелка, размытие | панель «Надписи и выделения»: появляются на дорожке под клипами, их можно двигать и растягивать по времени, а на кадре — мышью |
| Отмена | `Ctrl+Z`, `Ctrl+Y` |
| Сохранить | панель «Сохранить видео»: MP4, WebM или GIF; размер кадра, FPS, качество; есть прогресс и «Отмена» |
| Кадр в PNG | кнопка «Кадр в PNG» сохраняет текущий кадр с надписями |

Проект монтажа хранится только в памяти: пока окно не закрыто, всё на месте, но после закрытия нужно сохранить результат. Громкость выше 100% при предпросмотре не слышна (так работает проигрыватель), но в готовый файл попадает.

## Серия для лабораторной

Вкладка «Серия ЛР»: указываешь приставку, номер работы (например `ЛР` и `5`), при желании дисциплину и номер первого рисунка. Дальше каждый шаг — кнопка «Сделать шаг» или горячая клавиша `Ctrl+Shift+PrintScreen` (работает, даже когда окно скрыто).

- Файлы получают имена `ЛР5_шаг1.png`, `ЛР5_шаг2.png` … (шаблон меняется в настройках).
- Рисунки нумеруются сквозно по порядку шагов. Подпись собирается как «Рисунок N — описание». Если шаг удалить, номера рисунков пересчитаются, а номера шагов и имена файлов остаются.
- У каждого шага можно написать описание, «Переснять» снимок, открыть в редакторе, показать файл в папке. «Копировать подписи» кладёт в буфер весь список подписей.
- Папка серии: `Изображения\Скриншоты\Лабораторные\<дисциплина>\ЛР5`. Рядом лежит `series.json` — по нему «Отчётник» собирает отчёт. Формат: `kind: "moi-screenshot-series"`, `schema: 1`, `steps: [{ step, figure, file, text, caption, createdAt }]`, файлы указаны относительно папки серии.

## Настройки

Семь вкладок: «Основные» (язык русский/English, тема тёмная/светлая/как в Windows, цвет акцента, масштаб, автозапуск, трей), «Съёмка» (горячие клавиши, папка, формат, имя файла, подпапки по дате, задержка, звук, уведомления), «Серия ЛР», «Запись» (источник, звук, камера, формат, FPS, папка, лимиты, горячие клавиши), «Данные» (лимит истории, резервные копии, экспорт/импорт, сброс), «О программе» (иконка, версия, сведения о сборке) и «Что нового» (история всех версий).

## Данные, копии и безопасность

- Программа работает без интернета и ничего никуда не отправляет.
- На диск пишет только в выбранные тобой папки и в `%APPDATA%\MoiScreenshot`. Удаляет файлы только в Корзину.
- Резервные копии (`%APPDATA%\MoiScreenshot\backups`): автоматически раз в сутки при запуске, вручную и перед восстановлением, импортом и сбросом. Хранятся последние 10 каждого вида.
- Настройки старых версий (0.0.x и 0.1.0) переносятся сами, старый файл остаётся в `backups\settings-before-migration-v1.json` или `-v2.json`.
- Список записей входит в резервные копии, сами видеофайлы остаются в папке записей.

## Где лежат данные

| Что | Где |
| --- | --- |
| Настройки и история | `%APPDATA%\MoiScreenshot` |
| Снимки | `Изображения\Скриншоты` (папку можно сменить) |
| Записи экрана | `Изображения\Скриншоты\Записи` (папку можно сменить) |
| Серии ЛР | `Изображения\Скриншоты\Лабораторные` (папку можно сменить) |
| Резервные копии | `%APPDATA%\MoiScreenshot\backups` |

## Ограничения

- Режим «Весь экран» снимает один монитор (тот, где мышь). Склейки всех мониторов нет.
- Нет загрузки в интернет и прокрутки страницы, как в ShareX. Запись видео и GIF-экспорт есть, но запись идёт только с одного экрана.
- Запись окна с защитой от захвата или игры в полноэкранном режиме может дать чёрный кадр: это ограничение Windows.
- В видеоредакторе у всех клипов размер кадра берётся по первому клипу (остальные вписываются с чёрными полями).
- Автозапуск работает после установки (Setup). У Portable-версии путь к файлу может меняться, поэтому ему лучше пользоваться без автозапуска.
- Окна с защитой от захвата (некоторые банковские и DRM-программы) снимаются чёрным: это ограничение Windows.

## Проверка

`npm test` запускает автоматические проверки: логику (имена файлов, горячие клавиши, негатив, хранилище, миграция, копии, серия ЛР, переводы), оркестровку записи и видеоредактор с настоящим ffmpeg. Интерфейс проверялся отдельно в Chromium с подставным API (`python3 test/ui_test.py`).
